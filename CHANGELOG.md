# Changelog

All notable changes to the Notificator Node.js SDK are documented here.

## 0.1.1 - 2026-09-01

- Publish the SDK through npm trusted publishing with verifiable GitHub Actions provenance.

## 0.1.0 - 2026-08-13

- Introduces the official server-side client for the hosted Notificator API.
- Supports mobile push, account email, inbox, and connected-device delivery controls.
- Provides TypeScript declarations, request timeouts, cancellation, and structured API errors.
- Keeps the Notificator endpoint fixed to the official hosted service so platform credentials never enter user applications.
